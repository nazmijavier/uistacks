# Contributing

Thanks for helping make UI Stacks better.

- **Bugs:** open an issue with the component name, what you expected, what happened, and your browser. A short screen recording helps.
- **Ideas:** open an issue describing the screen you are building and the component you are missing.
- **Pull requests:** keep changes small and focused on one component. Match the existing style: Tailwind classes, the tokens in `styles/tokens.css`, Lucide icons, keyboard support and reduced motion.
